MP3Lumia - Nokia Lumia 929 / Windows 10 Mobile
==============================================

A Spotify-style music player for the songs already on the phone: tags, albums,
artists, playlists, a queue, a 10-band equalizer with 35 presets, crossfade,
sleep timer, lyrics and metadata editing. Local only: no account, no network.

FILES IN THIS FOLDER
  MP3Lumia.appx          signed ARM package for Windows 10 Mobile
  MP3Lumia-RootCA.cer    the root the package chains to - trust this on the phone
  MP3Lumia-Dev.cer       the signing certificate itself, for reference
  AppxManifest.xml       the manifest inside the package, for reference
  INSTALL.txt            this file

INSTALL - the same steps that worked for PrivateBrowse, FreePaint and MP4Lumia
  1. Copy MP3Lumia.appx and MP3Lumia-RootCA.cer into the phone's own storage,
     for example: This Device > Downloads > MP3Lumia.
     Do not leave them only in OneDrive.
  2. Settings > Update & security > For developers > Developer mode.
     Choose Developer mode, not "Sideload apps", then restart the phone.
  3. Open MP3Lumia-RootCA.cer from the phone's file manager and install it as a
     trusted root. If the page only shows certificate details with no install
     button, it is not installed yet.
  4. Open MP3Lumia.appx from the same folder and confirm the install prompt.
     It takes a few seconds; MP3Lumia then appears in the app list.
  5. If nothing appears, restart the phone and search All apps for MP3Lumia,
     or check Settings > Apps > Apps & features.

FIRST RUN
  Tap "Add music files" and pick songs from Downloads, Music, the SD card or
  OneDrive files kept on the device. "Add a folder" imports every song inside
  it. "Scan the Music folder" adds everything under This Device > Music.

IF SOMETHING GOES WRONG
  0x800B0109  root not trusted on the phone - install MP3Lumia-RootCA.cer
  0x80073CFF  not in Developer mode - step 2
  0x80073CF3  architecture or dependency conflict - use this package, not an
              older or different one
  0x80073CF0  truncated copy - copy MP3Lumia.appx again
  Settings > System > About shows the OS build. This package needs 10.0.10586
  or later; a Lumia Icon on Windows 10 Mobile reports 10.0.15254.
  A Windows 10 PC will refuse this file: it is a phone package.

PLAYBACK NOTES
  Audio is decoded by the phone's own Media Foundation stack through the app's
  audio element. MP3, WAV, AAC/M4A and WMA play on Windows 10 Mobile; FLAC is
  supported on later builds. The equalizer needs Web Audio; if the phone's
  engine lacks it the player still works and the EQ screen says so.
  Tags are read from ID3v2/ID3v1 (MP3), Vorbis comments (FLAC/Ogg) and MP4
  atoms (M4A), with the Windows music properties as the first choice on the
  phone. Editing a song or album keeps the change in MP3Lumia and, on the
  phone, also asks Windows to write the common fields back into the file.

ABOUT THE SIGNATURE
  MP3Lumia Root CA is self-signed, CA:true, path length 0, valid 10 years.
  MP3Lumia Dev is issued by it with the Code Signing EKU, valid 3 years.
  Neither is timestamped and neither is from the Store: fine for sideloading,
  unsuitable for anything else.
