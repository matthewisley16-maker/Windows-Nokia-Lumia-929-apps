5 GHz: YES 802.11ac: YES WPA2-PSK: YES WPA3: NO Wi-Fi 6/ax: NO
The short version

The Icon's radio is Wi-Fi 5 hardware. It has always done 2.4 GHz and 5 GHz at 802.11ac. It does not do WPA3 or Wi-Fi 6, and no app can add those — WPA3 lives in the firmware and driver, and WP8.1 exposes no way to replace the supplicant.

So this app does the two things that actually work: it gets you onto the 5 GHz band at full ac speed, and it fixes the router settings that make the phone refuse to join at all.

What is it doing wrong?

If it is 5 GHz only: the phone is probably looking at a channel it will not use — DFS channels (52–144) or an "auto" channel that lands on one. Pin the 5 GHz band to 36, 40, 44, 48 or 149, 153, 157, 161.

If band steering is on (one SSID for both bands), WP8.1 often parks on 2.4 and never hops. Give the 5 GHz band its own SSID, e.g. MyNet-5G, and join that one directly.

If the SSID is hidden, unhide it. The phone can join hidden networks but it scans badly and drops them.

If the name has emoji, accents or spaces, rename it to plain ASCII letters, digits and hyphens. Keep it under 32 characters.

This is the classic one. A modern router set to WPA2/WPA3 mixed with Protected Management Frames set to Required will list its name to the phone and then reject every handshake. The phone support list ends at WPA2-PSK (AES).

Fix it in this order: security mode WPA2-PSK (AES/CCMP) → PMF/802.11w Disabled or Optional → fast roaming 802.11r off → save and reboot the router → on the phone, Settings › Wi-Fi, tap the network, delete it, then re-join.

Also check MAC filtering. If it is on, the phone's MAC has to be on the allow list. Find it in Settings › about › more info.

Turn Wi-Fi off and on again, then airplane mode on and off. That clears a stuck DHCP lease.

If it is a hotel, cafe or campus network with a sign-in page, IE on WP8.1 often fails to pop the portal. Open http://neverssl.com in Internet Explorer to force the login page to appear.

If only this phone has no internet on a working network, set a static DNS on the phone: Settings › Wi-Fi › (hold network) › edit › DNS › manual, primary 1.1.1.1, secondary 8.8.8.8.

Yes, this phone does 5 GHz

The Lumia 929 (Icon) has a Qualcomm Snapdragon 800 with a dual-band 802.11ac radio. WP8.1 ships drivers for it. There is nothing to install and nothing to unlock — if you are stuck on 2.4 GHz, the router is telling it to be stuck there.

On an 80 MHz ac channel that is a 433–866 Mbit link rate, so expect anything from 40 to 400 Mbit in real life depending on distance and how many other devices are shouting on the channel.

What the 5 GHz band must look like

1. One name per band

Turn off band steering (also sold as Smart Connect, One Wi-Fi Name, Self-Organizing Network, or "seamless roaming"). Name the 5 GHz radio something like Home-5G. Then on the phone pick Home-5G and it will stay there.

With steering on, the router hands the phone 2.4 GHz first and the phone never asks to move. That is the whole "I am stuck at 2.4" story.

2. WPA2-PSK AES — and check the 5 GHz band separately

Most modern routers keep per-band security pages. People fix 2.4 GHz and leave 5 GHz on WPA3. Open the 5 GHz tab in the router UI and set it to WPA2-Personal / WPA2-PSK with AES or CCMP.

3. PMF must not be "Required"

802.11w Protected Management Frames is mandatory under WPA3 and optional under WPA2. WP8.1's supplicant never implemented it. When a router sets PMF = Required on the 5 GHz radio, the phone sees the network, tries, and fails every time, usually with a generic "couldn't connect".

4. Channel: stay out of DFS

Channels 52–144 are radar channels. Radios of this era frequently refuse to associate on them, or drop the link when a radar event fires. Use 36, 40, 44, 48, or 149 – 161.

Never leave the channel on Auto: auto-selection loves to pick a DFS channel that is quiet, which is exactly the one your phone will not use.

5. Width and mode

Set mode to 802.11 a/n/ac mixed and width to 80 MHz. If you get drops, go to 40 MHz. An "ax only" or "11ax" mode will exclude this phone entirely, so make sure Wi-Fi 6 compatibility / "legacy mode" is on, or drop the band to ac.

6. Region and channel legality

If the router is set to a region where 149–165 is not allowed, or the phone's region differs, the upper channels look invisible. Set the router's country correctly and prefer 44 if you are unsure.

Prove you are actually on 5 GHz

  1. Settings › Wi-Fi › the connected network shows Connected.
  2. Join the -5G name specifically. If both names are visible in the list, the band is broadcasting and the phone can hear it.
  3. Speed test in Internet Explorer: anything over ~90 Mbit means you are on 5 GHz. 2.4 GHz caps out around 40–70 Mbit on a good day.
  4. Router UI shows the phone's MAC on the 5 GHz client list. That is the definitive proof.
What you cannot have

WPA3, WPA3-only networks, 802.11ax/Wi-Fi 6 features, WPA3-Enterprise, and 6 GHz are firmware and driver features. There is no app, no registry edit and no sideload that adds them to WP8.1. Any page promising a "WPA3 enabler app" for Windows Phone is a scam.

Find the 5 GHz page first

Every router below has a separate 2.4 GHz and 5 GHz page. The settings you change have to be made on the 5 GHz page, and then again on 2.4 GHz if you also want the fallback to work.

xFi app › Wi-Fi › Wi-Fi details, or 10.0.0.1. Turn off WPA3 and WPA3 Transition. Set security to WPA2-PSK (AES). Rename the 2.4 and 5 GHz bands separately if your firmware exposes it; otherwise disable band steering. Set 5 GHz channel to 44, width 80, mode a/n/ac.

192.168.1.1, admin / admin or the sticker password. Wireless › 5 GHz › Security: WPA2-PSK AES, and untick WPA3. Wireless › 5 GHz › Basic: mode 802.11a/n/ac, channel 44, width 80. Give 5 GHz a distinct SSID.

192.168.1.254. Home Network › Wi-Fi › Advanced: turn off WPA3, and look for Wi-Fi Compatibility mode and turn it on — that one toggle fixes a lot of 2013–2015 devices. Set both bands to WPA2-PSK AES and split the names on the same page.

myfiosgateway.com. Wireless › Security: WPA2, WPA3 Transition Mode OFF. Wireless › Advanced: disable SON / Self-Organizing Network so the two bands get separate names, then set the 5 GHz channel to 44 or 157.

Archer: tplinkwifi.net › Wireless › 5 GHz › Wireless Security: WPA2-PSK, AES, and set Version to WPA2-PSK, not "WPA2/WPA3". Under Advanced, PMF = Disable. Smart Connect off so the bands get separate names.

Deco: the app forces one SSID. Workaround: create a guest network and pin it to 2.4 GHz for the phone, or put a WPA2 access point behind it (Plan B tab).

routerlogin.net or orbilogin.com › Wireless Setup › Wireless Network: untick Enable WPA3, set Security to WPA2-PSK [AES]. To get 5 GHz at all you must turn off Smart Connect, which then shows separate 2.4 and 5 GHz SSID boxes. Set 5 GHz channel 44, width 80.

router.asus.com › Wireless › 5 GHz: Authentication Method = WPA2-Personal, WPA Encryption = AES. Set Protected Management Frames to Disable. Turn off 802.11ax / Wi-Fi 6 mode on 5 GHz if the phone still fails, and turn off Agile Multiband. Uncheck "Enable Smart Connect" to split the SSIDs.

These hide almost everything. eero: app › Settings › Network settings, turn WPA3 off. Nest: Home app › Wifi › Settings › WPA3, set to off. Neither lets you split the bands, so the reliable route for this phone is a WPA2 access point or the guest network (Plan B).

Settings › WiFi › your network: Security = WPA2 Personal, PMF = Optional (not Required). Make a 5 GHz-only SSID with band steering off, channel width 80, and disable "Wi-Fi 6" if the AP lets you.

Sky Hub: 192.168.0.1 › Wireless › 5 GHz › security WPA2-PSK. BT Smart Hub: 192.168.1.254 › Advanced settings › Wireless › turn off "Smart Wireless"/band steering to split names. Virgin Hub 4/5: 192.168.0.1 › Advanced › Wireless › Security, WPA2-PSK only, and disable WPA3 if listed.

If you cannot change the main router

Rented gear, landlord's router, locked-down mesh, WPA3-only building WiFi. You can still get this phone onto a fast 5 GHz network without touching the main box — put a cheap WPA2 access point on its LAN and let the phone join that.

Plan B1 — WPA2 access point on the LAN

  1. Any router or travel router that can run in Access Point mode with WPA2-PSK. A GL.iNet travel router is about $30 and does exactly this.
  2. Plug it into a LAN port on the main router with an Ethernet cable.
  3. On the access point: 5 GHz radio on, WPA2-PSK AES, PMF off, channel 44, width 80, SSID something like Home-Legacy-5G.
  4. Join Home-Legacy-5G on the phone. You get real 5 GHz ac speed and normal internet, because the AP bridges to the main router over the wire.

Plan B2 — mesh node in bridge mode

An old router flashed with OpenWrt, or any spare AP, can repeat the network as a second SSID. Same config: WPA2-PSK AES, own 5 GHz SSID, PMF off. Repeating halves throughput, but it is still far better than 2.4 GHz and it works when the main router will not budge.

Plan B3 — phone hotspot

An Android or iPhone hotspot can be set to WPA2 and 5 GHz in most cases, which the Lumia will join. Fine for a quick sync, but it burns mobile data, so treat it as a stopgap.

What not to waste time on

There is no WPA3 patch for WP8.1, no third-party Wi-Fi supplicant, and no interop layer — the OS gives apps no access to the Wi-Fi driver. Registry hacks and "WiFi Booster" apps on the Store do not do it either. The band is the thing you can control, and the access point is the lever.

One-paragraph summary

Switch the 5 GHz radio to WPA2-PSK AES with PMF off and a channel of 44 or 157, give it its own SSID, turn off band steering on the router, delete the old network on the phone and join the -5G name. That gets the Lumia 929 onto the newest network it can physically speak to, at full 802.11ac speed. Anything beyond that — WPA3, Wi-Fi 6, 6 GHz — needs firmware that does not and will not exist for this phone.
